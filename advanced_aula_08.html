Grammar: Word Formation

As regras dos prefixos negativos, dos sufixos e como uma raiz vira uma família inteira.

un- (o mais comum): happy → unhappy · clear → unclear. dis-: agree → disagree · honest → dishonest.
im- antes de p/m (possible → impossible, polite → impolite) · ir- antes de r (regular → irregular) · il- antes de l (legal → illegal).
mis- = errado (understand → misunderstand) · over-/under- = demais/de menos (overwork, underestimate).
📐 Regra: im-/ir-/il- seguem o SOM da primeira letra da raiz. Erro clássico de brasileiro: "unpolite" ❌ → impolite ✅.
Verbo → substantivo: inform → information (-tion) · develop → development (-ment) · perform → performance (-ance).
Adjetivo → substantivo: happy → happiness (-ness) · able → ability (-ity).
→ adjetivo: rely → reliable (-able = que dá pra) · hope → hopeless (-less = sem) · care → careful (-ful = cheio de) · danger → dangerous (-ous).
employ → employer (quem contrata) · employee (quem é contratado) · employment (o emprego) · unemployed (desempregado).
decide → decision · decisive · indecisive. create → creation · creative · creativity · creator.
Fazendo verbos: modern → modernize · simple → simplify · short → shorten · able → enable.
