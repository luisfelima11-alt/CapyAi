Grammar: Used to & Would

Hábitos e estados do passado, would para ações repetidas, e a confusão clássica used to vs be/get used to.

FORM: used to + base verb (for ALL subjects): "I/She/They used to..."
USE for: (a) past habits that stopped: "I used to smoke." (b) past states no longer true: "She used to be shy." (c) past situations: "We used to live abroad."
Negative: didn't use to (NO 'd' — "use to", not "used to" after didn't): "He didn't use to like it."
Question: Did you use to...? "Did you use to play tennis?"
📐 Regra: used to ALWAYS refers to the past — there is no present form. ❌ "I use to go" (for present habit) → ✅ "I usually go."
"Would" can replace "used to" for REPEATED PAST ACTIONS: "Every summer, we would visit our grandparents." = "we used to visit."
BUT: "would" CANNOT be used for PAST STATES (be, have, like, know, etc.):
✅ "I used to BE shy." / ❌ "I would be shy." (state — wrong!)
✅ "We used to HAVE a dog." / ❌ "We would have a dog." (state — wrong!)
📐 Regra: Use 'would' only for actions you can picture happening repeatedly. Use 'used to' for both actions AND states. When in doubt, use 'used to' — it always works!
USED TO + base verb = past habit: "I used to swim every day." (past, now stopped)
BE USED TO + noun/gerund = be accustomed: "I am used to swimming in cold water." (it's normal for me now)
GET USED TO + noun/gerund = become accustomed: "I'm getting used to the cold water." (process of adapting)
"I used to drive on the right." (past habit) vs "I'm used to driving on the left now." (accustomed) vs "I'm still getting used to driving on the left." (adapting).
📐 Regra: "used to + verb" = PAST. "be/get used to + -ing" = PRESENT adaptation.
