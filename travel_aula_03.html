Grammar: Restaurant English

Estruturas para pedir, perguntar e descrever preferências alimentares.

"I'd like the grilled salmon, please." → Educado e natural.
"We'd like to see the dessert menu." → Para grupos.
"I'd like my steak medium-rare." → Com preferência de cozimento.
💡 Dica: "I'd like" é mais educado que "I want". Sempre use em restaurantes formais.
"What do you recommend?" → Pedindo sugestões.
"Is this dish vegetarian?" → Verificando restrições.
"Does it contain nuts?" → Para alergias.
"What comes with the main course?" → Acompanhamentos.
RARE= mal passado → "I'd like my steak rare, please."
MEDIUM= ao ponto → "Medium for me, thank you."
WELL-DONE= bem passado → "Well-done, please."
PREFER= "I prefer vegetarian options."
AVOID= evitar → "I avoid gluten."
