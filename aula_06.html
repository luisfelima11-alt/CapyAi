📐 Grammar

CAN, COULD & SHOULD — usos e diferenças.

Regra de Ouro

Modal + verbo base (sem TO)

CAN ⚡ COULD 🔑 SHOULD 🛡️

Mesma forma para todos os sujeitos: can (sem -S!)

✅ I can speak English! → Consigo falar inglês!

✅ Can I use your pen? → Posso usar sua caneta?

✅ She can run fast. → Ela consegue correr rápido.

❌ She cans run / She can to run

Forma passada de CAN + pedidos mais formais/educados

✅ Could you help me? → Você poderia me ajudar? (mais educado)

✅ I could swim when I was 5. → Eu conseguia nadar quando tinha 5 anos.

✅ Could you repeat that? → Poderia repetir?

Dar conselhos ou recomendações — o que é melhor fazer

✅ You should practice every day. → Você deveria praticar todo dia.

✅ She shouldn't skip classes. → Ela não deveria faltar aulas.

✅ Should I call first? → Devo ligar primeiro?

⚡ Can you help me? → Pedido direto, informal

🔑 Could you help me? → Pedido educado, mais formal

🛡️ You should help me. → Conselho / sugestão

💡 Todos seguidos de verbo BASE sem TO!
