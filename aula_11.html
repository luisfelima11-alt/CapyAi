📐 Grammar

Como formar e usar comparativos.

As 3 Regras

📏 Curtos (1-2 sílabas): +ER → big → bigger / tall → taller
📚 Longos (3+ sílabas): MORE + → beautiful → more beautiful
⚡ Irregulares: good → better / bad → worse / far → farther

Maioria dos adjetivos de 1-2 sílabas: adicione -ER

fast → faster | tall → taller | old → older | cold → colder

🔸 Termina em -E: só +R → nice → nicer | large → larger

🔸 Termina em consoante+Y: Y→IER → happy → happier | easy → easier

🔸 CVC curto: dobra consoante → big → bigger | hot → hotter | sad → sadder

3+ sílabas: use MORE antes do adjetivo (nunca -ER!)

beautiful → more beautiful | expensive → more expensive

intelligent → more intelligent | interesting → more interesting

dangerous → more dangerous | serious → more serious

Estes não seguem nenhuma regra — é só memorizar!

good → better (nunca: gooder / more good)

bad → worse (nunca: badder / more bad)

far → farther / further

"Did you do well? — Yes, I did even better today!"

Use THAN para comparar dois elementos:

She is taller than me. / English is easier than I thought.

This bag is more expensive than that one.

He is better than before — practice works!

Use AS + adjetivo + AS para dizer que dois elementos são iguais:

I am as tall as my brother. → Sou tão alto quanto meu irmão.

Is English as hard as Japanese? → É tão difícil quanto?

She's not as fast as before. → Ela não é tão rápida quanto antes.

Leo! Look — the otter is faster than the capybara in swimming! But capybaras are calmer — they never panic.

Wow! And the parrot is more intelligent than the monkey in the language test! The monkey is better at climbing though.

🐾 Capy Yara

Exactly! Every animal has something stronger than the others. The bear is heavier than everyone, but the fox is more cunning.

🧑‍🦱 Leo

Is English harder than learning to swim like an otter? Sometimes it feels more difficult than I expected!

🐾 Capy Yara

Ha! English is easier than you think — and you are getting better and better every day. That's way more impressive than any competition!

🧑‍🦱 Leo

That's more like it! Each day I feel stronger and more confident. The harder I work, the better I get! 🏆
